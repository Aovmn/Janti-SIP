Website ini tentang apa?

SIPETRA Janti adalah website WebGIS desa yang menampilkan data pertanahan secara lebih ringkas, visual, dan mudah diakses melalui browser tanpa harus membuka sistem pemetaan yang rumit.

Apa yang bisa dilihat?

Pengunjung dapat membaca pengantar situs, melihat informasi dasar desa, lalu mengeksplorasi batas administrasi, penggunaan lahan, dan status hak tanah pada peta interaktif. Leaflet mendukung penayangan GeoJSON dengan popup dan gaya layer yang dapat dikustomisasi melalui HTML, CSS, dan opsi popup.

Informasi dasar desa

Pengantar wilayah sebelum masuk ke peta interaktif

Urutan seperti ini membantu pengguna memahami konteks wilayah lebih dulu, lalu baru melihat data spasialnya. Best practice landing page juga menekankan pentingnya konten statis yang menjelaskan layanan, informasi dasar, dan arah navigasi yang jelas.

Lokasi administratif

Desa Janti berada di Kecamatan Polanharjo, Kabupaten Klaten, Provinsi Jawa Tengah, dan menjadi wilayah yang tepat untuk ditampilkan dalam format WebGIS desa.

Tujuan website

Website ini berfungsi sebagai sarana penyajian data pertanahan secara terbuka, lebih mudah dipahami, dan lebih menarik secara visual untuk pengguna umum maupun pihak desa.

Isi data

Layer utama yang ditampilkan meliputi batas administrasi, penggunaan lahan, dan status hak tanah yang dimuat dari file GeoJSON statis di repository.

Cara membaca

Pengguna bisa menyalakan atau mematikan layer, mengganti basemap, lalu klik fitur pada peta untuk melihat popup atribut yang dibuat lebih rapi dan mudah dibaca. Popup di Leaflet memang bisa diisi HTML kustom dan dipercantik dengan CSS.

Masuk ke eksplorasi data spasial

Layer dimuat dari file GeoJSON lokal melalui `fetch()` lalu dipetakan menggunakan `L.geoJSON(...)`, yang merupakan pola umum untuk peta statis berbasis Leaflet. Legenda dan popup di bawah ini juga dikustomisasi agar tampil lebih jelas dan lebih nyaman dibaca.

Catatan website

Tetap ringan, tapi tampil lebih enak.

File ini tetap berupa static HTML satu halaman yang cocok untuk GitHub Pages, sementara peta memakai Leaflet dan GeoJSON statis dari repository. GitHub Pages cocok untuk hosting file statis, dan Leaflet menyediakan popup, kontrol, serta konten HTML kustom untuk peta interaktif.
